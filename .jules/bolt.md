## 2024-11-20 - [Optimization] Pre-compute O(N) derived aggregates during Map grouping passes
**Learning:** In list views (like `DesktopGrid`, `MobileTimeline`, or `GameList`), calling an O(N) utility function like `getHomeAwayCounts(dayGames)` inside the component's render `.map()` loop creates redundant inner O(N) array traversals on every React render cycle.
**Action:** When grouping data into Maps, arrays, or objects in a `useMemo` block or initial setup pass, always compute and store derived aggregate statistics inline inside the same data structure (e.g., `{ games, homeCount, awayCount }`), avoiding the need to traverse the arrays again during render.
