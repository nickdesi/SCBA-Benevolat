We can cache the parsed object in memory inside `storage.ts`!
```ts
let cachedRegistrations: Record<string, string[]> | null = null;

export const getMyRegistrations = (): Record<string, string[]> => {
  if (cachedRegistrations) return cachedRegistrations;
  try {
    const data = localStorage.getItem('scba-my-registrations');
    cachedRegistrations = data ? JSON.parse(data) : {};
    return cachedRegistrations;
  } catch {
    return {};
  }
};
// And in saveMyRegistration / removeMyRegistration we update the cache.
```
This would make `getMyRegistrations()` extremely fast (O(1) memory lookup) instead of O(N) JSON parse and DOM storage read every time it's called.
